# 旧生態系比喩と現行語の対応

**読むためだけの表である。新しく書くときは使わない。**
現行ドメイン語彙の正典は [`domain.md`](../../domain.md)。本書はそこへ辿り着くための橋である。

## なぜ要るか

`domain.md` は「旧生態系比喩は現行UI・現行仕様では使用しない」と定めている。
しかし**コードのコメント・SQL・テスト名には残っている**（2026-08-19 実測）。

```
森 179箇所   林 152箇所   木 56箇所
```

正典側に対応表が無いため、コードで `森` に出会ったAIも人間も、
それが正典のどの語なのかを辿れなかった。`C-45` を引いても
「現行UIの語彙は…に統一した」とあるだけで、**写像がどこにも無い。**

（`domain.md` は `.audit/MANIFEST.sha256` の封印対象で、実装セッションからは編集できない。
本書は封印の外側に置いた橋である。`domain.md` へ1行のポインタを入れるなら、
`.tmp/domain-glossary.patch` を適用して `kurosaki install --repo .` で再封印する。）

## 対応

| 旧語 | 現行語 | 実体 | 典拠 |
|---|---|---|---|
| 森 | アプローチ可能圏 / 構成コミュニティ | `schools`（旧識別子 `forest`） | `C-45`、`src/queries/cockpit.ts` |
| 林 | 接点継続中 | 直近 `active_window_days` 日以内に接点がある候補者（`identified_person_cum`） | `D-3`、`db/migrations/0002_views.sql` |
| 木 | 応募 | その年度に応募した候補者 | `D-3`、`src/queries/dashboard.ts` |
| 幹 | 合格 | 最終選考ステップへの有効な advance（`accepted`） | `db/migrations/0002_views.sql` |

典拠は `pnpm decisions:show C-45` / `pnpm decisions:show D-3` で読める。

## 読むときの注意

- **林・木・幹の3段は人を数える。森は単位が違う**ため同じファネルに含めない
  （`db/migrations/0002_views.sql`）。
- 「種」は比喩ではない。コード中の出現はすべて「種類」「一種」「4種」等である。
  当初これを比喩と誤って数えた（`git grep -c` は該当**行数**であって出現数ではない）。
- 同じ `森` が組織階層（`森 → 林 → 人` のズーム）とファネルの両方で使われていた。
  **この二重性が比喩を廃止した理由である**（`C-45`）。
- 適用済みSQLの `forest` / `community` 識別子は、名前を変えると既存DBと移行履歴を
  壊すため**内部互換識別子としてだけ残る**。ユーザー向け用語ではない（`domain.md`）。
