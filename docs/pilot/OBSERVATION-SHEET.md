# Observation Sheet（観測シート）

**対象者ごとに1枚コピーして使う。** 実施中に書き、当日中に埋め終える。

書き方の約束が3つある。

1. **解釈ではなく、起きたことを書く。**
   ×「担当の選び方が分かりにくい」／〇「担当の欄で 8 秒止まり、`/operations` を開いた」
2. **相手の言葉をそのまま書く。** こちらの語（森・林・木・Forest）に翻訳しない
3. **迷いは秒で書く。** 3秒以上のためらいは全部書く

## 1. 手が止まった場所

**操作が進まなくなった場所。** 画面が答えを出せていない場所である。

| # | 時刻 | どの画面・どの欄 | 何をしようとしていたか | 止まった秒数 | どう抜けたか（自力／こちらが答えた／諦めた） |
|---|---|---|---|---|---|
| 1 | | | | 秒 | |
| 2 | | | | 秒 | |
| 3 | | | | 秒 | |

> **「こちらが答えた」が1件でもあれば、そこは確実に画面の誤りである。**

## 4. 想定外の操作

**こちらが想定していない使い方。** ここに次の設計が入っていることが多い。

| # | 時刻 | 何をしたか | なぜそうしたか（本人の言葉） |
|---|---|---|---|
| 1 | | | |
| 2 | | | |

例: 別のタブで `/people` を開いて突き合わせた／ブラウザの戻るを使った／
検索から入ろうとした／メモ帳に転記した

## 7. 開発側との言葉の違い

**`domain.md` を直す材料になる。** ここが埋まったら、
語を捨てずに `domain.md` 10節へ未決として足す。

| # | 画面の語 | 相手の語 | 同じものか | 気づいたきっかけ |
|---|---|---|---|---|
| 1 | 森 | | 同じ / 違う / 一部重なる | |
| 2 | 林 | | 同じ / 違う / 一部重なる | |
| 3 | やること | | 同じ / 違う / 一部重なる | |
| 4 | 判定 | | 同じ / 違う / 一部重なる | |
| 5 | | | 同じ / 違う / 一部重なる | |

> **「違う」が付いた語は、画面の言い換えでは済まない。**
> 世界設定（`domain.md`）の側が足りていない可能性を先に疑う。

## 9. 改善アイデア

**相手が言ったアイデアと、こちらが思いついたものを分けて書く。**
どちらも**この時点では仮説である**（`REVIEW.md` の昇格条件を通すまで）。

### 相手が言ったこと

| # | 言葉（そのまま） | どの観測に紐づくか（1〜8の番号） |
|---|---|---|
| 1 | | |
| 2 | | |

> **要望は観測ではない。** 「あったら良い」と言われただけのものを
> Validated Operator Problem にしない（`REVIEW.md`）。

### こちらが思いついたこと

| # | 内容 | どの観測に紐づくか | 紐づく観測が無い場合はそう書く |
|---|---|---|---|
| 1 | | | 紐づく観測: 有 / **無** |
| 2 | | | 紐づく観測: 有 / **無** |

> 「紐づく観測: 無」のものは **Product Backlog** 行きである。

## 10. 立ち会いの自己点検

| 質問 | はい / いいえ |
|---|---|
| 操作を教えてしまった回数 | 回 |
| 画面を弁護してしまったか | |
| 「分かりますか？」と訊いてしまったか | |
| 相手の言葉を、こちらの語に置き換えて書いた箇所はあるか | |
| 手が止まったとき、5秒待てたか | |

**教えてしまった回数が多いほど、この回の観測は薄い。** 次回の運びを直す。

---

## 11. この回の成否

`CHECKLIST.md` の成功条件を写して判定する。

| 条件 | 満たしたか |
|---|---|
| 手が止まった＋迷った が合計3件以上 | |
| 相手の言葉を5語以上そのまま記録 | |
| 言葉の食い違いが1語以上 | |
| 画面の外に書きたくなったものが1件以上 | |
| 操作を教えずに1周通せた | |

**迷いが0件だった回は、Pilot として失敗である。**
プロダクトが完璧だったのではなく、**観測が取れていない**と考える。
