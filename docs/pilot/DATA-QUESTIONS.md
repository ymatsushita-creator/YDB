### 選考ステップ

旧システムに定義されている順序は8つ。


`保留` と `辞退` は途中の分岐状態。
不合格は書類選考・グループ面接・最終面接の各段階で発生する。

```
応募受付 → 書類選考 → グループ面接 → 最終面接
```

合格・補欠合格・辞退・保留・承諾書提出は**ステップではなく結果・状態**として扱う。
