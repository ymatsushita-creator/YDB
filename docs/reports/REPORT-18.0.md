## 事故と、そこから直した設計

1. **`<div role="region">` → `<section>` にしたら `tests/45_home.test.ts` が落ちた。**
   テストが**器の要素名で本文を切り出していた**ため空を返し、その先の検査が全部素通りしていた。
   切り出しを class 基準に変えた（要素名に依存しない）。
2. **allowlist 候補の一覧に検出行を引用したら、その引用で pre-commit が落ちた。**
   検出について書いた文書が検出源になる —— S13 と同型の自己参照。実体の行は追跡外へ出した。
3. **allowlist の指紋を間違えた。** 監査所見（ファイル単位）の指紋を入れたため1件も除外されず、
   `kurosaki scan --format json` から**検出1件ごとの指紋**を取り直した。
