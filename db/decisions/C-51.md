### C-51. 学年ではなく「期」。年度に期の番号を持たせ、スクロールを無くした

実行⑨。依頼者から3点の指示 ――
**「学年というものはそもそも存在しない。1期、2期とあって、次の募集は3期」**
**「アプローチ画面の団体別リーチとチャネル別アトリビューションはタブ切り替えに」**
**「スクロール無しで成り立つようにして」**

#### 学年は「記録層に無いもの」ではなく、存在しない概念だった

画面は「学年（4年生・2026年卒）」を**足りない実装として**出していた。
無い列を欲しがる注記は、次に触る人にその列を作らせる。**注記ごと消した。**

代わりに 0021 で `seasons.cohort_number` を足した。
**これは新しい事実ではなく、入れる場所が無かっただけである** ――
`db/seeds/0002_season_2026.production.sql` は最初からこう書いていた。

> 記録できなかったものが2つある。
> 1. 「NEO ACADEMIA 2期生」という名称。seasons に名前の列が無く、
>    enrollment_year（整数）しか持たない。期の呼び方は今は入らない

**2026年度 = 2期は受領済みの事実**なので、マイグレーションで埋めた。

- **enrollment_year から導かない。** 「年度の若い順に1,2,3…」で数えれば列は
  要らないが、**募集を1年休んだ年があると番号がずれる。** 期は運営が数えるもので、
  暦から導けない
- **NULL 可にした。** 本番にはすでに 2026 の行があるかもしれず、NOT NULL を
  後付けすると値の無い行1つで適用が止まる。分からない期を 0 期や 1 期で埋めない
- 画面の呼び名は `seasonLabel()` 1箇所で決める（期があれば期、無ければ年度）

★ **3期の年度はまだ作っていない。** 日程も定員も未受領で、推測で埋めない。

#### アプローチ画面をタブにした

2つの表を縦に積むと画面がスクロールになる。どちらも「どこから来ているか」への
答えなので、**同じ場所で切り替える。**

#### スクロールを無くす過程で、もっと悪い状態を2度作った

| # | 何が起きたか | 見つけ方 |
|---|---|---|
| 1 | `.hh-main` が 336px はみ出し、`overflow:hidden` で**中身が切れて到達できなくなった** | DOM の scrollHeight/clientHeight を測った |
| 2 | 直したつもりが 222px 残った。原因は `.hh-main` の `display:flex` が、前回の CSS 差し替えで消えていたこと | 同上（computed display が block だった） |
| 3 | 週カレンダーの格子が 155px はみ出して、下の時間帯が切れた | 同上 |

**切るのはスクロールより悪い。** スクロールは気づけるが、切れた中身は
気づけない。**「スクロールが無い」を、見た目だけで確認しない。**

直し方は3つ。
- 高さの連鎖を切らさない（flex/grid の子は既定で `min-height:auto` なので 0 へ落とす）
- カレンダーの行を可変（`minmax(30px, 1fr)`）にし、入りきらないときだけ格子の中で送る
- 「この画面にまだ無いもの」を `<details>` に畳む（常時開くと1画面ぶん高さを食う）

**全部を詰めて字を小さくする方向は取っていない。** 読めない画面は
スクロールが無くても使えない。**送る場所を、ページからカードへ移しただけである。**

#### 確かめ方

`pnpm test`（363件）・`tsc --noEmit`・`pnpm build`。
デモ経路で DOM を測って確認した ――
`document.documentElement` がスクロールしないこと、
**`overflow:hidden` ではみ出している要素が0件であること**（切れた中身が無い）、
帯と期の切替が「2期／1期」と出ること、アプローチのタブが2つとも表を出すこと。
