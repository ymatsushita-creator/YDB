### 自動保存は「見た目だけ」ではない

`app/_components/auto_save.tsx` は、入力欄からフォーカスが外れた時、または
打鍵が止まった時に**フォームを自動送信する。** 使われているのは3画面 ――
KPI の編集（`app/kpis/page.tsx`）・候補者の確度（`app/people/[id]/page.tsx`）・
面接の評価（`app/interviews/[evaluation]/page.tsx`）。

つまり保存ボタンを押さなくても書き込まれる。**いつ DB に書かれるかが変わる。**
依頼者へこの点を分けて説明し、**残す判断を受けた。**

### 判定は画面へ移していない

許可を広げたのは**書き込みの契機**であって、判定ではない。
`AutoSaveForm` は `action` を受け取って呼ぶだけで、値の可否は今までどおり
`src/commands/` が決める（C-95 / C-104 の骨格は動いていない）。
`'use client'` を数え続けるのは、この境界が崩れたときに気付くためである。

```

app/_components/auto_save.tsx          自動保存。**本項で許可**

```
