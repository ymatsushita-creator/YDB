#### ★ 流す帯を**縮ませない**（5度目）

`.hh-criteria-track` は送り箱（flex）の子なので、`width: max-content` を
指定しても**縮められる。** 縮むと `translateX(-50%)` の半分が
「2組ぶんの半分」でなくなり、**1周したところで継ぎ目が飛ぶ。**
`flex: 0 0 auto` を添えた ―― C-66 / C-113 / C-128 と**同じ手当ての5度目**である。
