## C-217 経営層セットのパイロット。エクセルで呼び名と実データを突き合わせた

依頼者の指示（実行⑱）――「わからないことがあればすべてエクセルの二個のうち
どれかにあるのでそこから探して取り組んで」「とにかくテストを回してくれ」。

### エクセルで解けたこと

**① 段の呼び名は、こちらの取り違えではなかった。**
`013_選考フロー`（1冊目）の通常選考フローは
**初期接点 → ステージング → エントリー → 書類選考 → グループ面接 → 最終面接 →
入学手続き**。記録層の並び（応募受付・書類選考・グループ面接・最終面接）と
一致する。C-216 でタブを段名で引く形に直したのは、この表と合っている。

**② 「2次選考」は運営の言葉である。**
`2期生応募フォーム(rawdate)` の設問に「**2次選考グループ面談へのご案内**」がある。
つまり「グループ面接」と「2次選考」は**どちらも運営の語**で、タブの
「3. 2次選考」は言い換えではない。**こちらで統一しない**（Pilot Rule）。

**③ 応募を作る口が画面に無いのは、運用と合っている。**
応募は Google フォーム（`2期生応募フォーム(rawdate)` /
`【追加募集】2期生応募フォーム(rawdate)` / `009_アカデミア説明会応募フォーム`）で
受け取り、取り込む。画面に手入力の口が無いのは欠けではない。

### エクセルで見つかった、依頼者の判断が要ること

`2期応募管理2.xlsx` の **「シート52」** に選考結果の実データがある
（氏名のある39行）。C-214 で「Excelに無い」と判断したのは**取り違えである。**

| 列 | 実データ |
|---|---|
| 一次選考結果 | 39件・**0〜16** |
| 二次選考結果 | 39件・0〜67.3 |
| 最終選考結果 | 合格 30 / 辞退 3 / **補欠 5** / 不合格 1 |
| 書類選考内容 | 29行に本文 |

★★ **取り込んでいない。** 理由は2つで、どちらも記録の意味が変わる ――

1. **一次選考結果の最大は16。** 依頼者は C-212 で書類選考を**10点満点**へ変えた。
   16点は今の記録層に入らない（`scale_max = 10`）。10点へ換算するのも、
   満点を16へ戻すのも、**依頼者が決めること**である。創作も換算もしない。
2. **「補欠」という結末が記録層に無い。** 結末は合格・辞退・不合格・無効化・
   選考中の5つで、補欠5件の置き場が無い。

★ シート52 には**実在の個人名**が入っている。パイロットにも
スクリーンショットにも使っていない（CLAUDE.md）。

### 経営層セット（all 層）で回して直したもの

- **連携団体の空表示**が「この年度に団体がまだない」だった。団体は期を持たない
  （C-213）ので、期を替えれば出てくるように読める。文言を直した。

### 経営層セットで見えた、依頼者の判断が要ること

- **「欲しい人ランキング」は、採点済みの段が違う人を同じ 100.0 で並べる。**
  書類選考だけ満点（10/10）の人と、最終面接まで満点（58/58）の人が同順1位。
  率としては正しいが、「誰を採るか」を見る画面としては読めない。
  区別するなら、どの段まで採点済みかを出す形になる（画面の形は依頼者の指示）。
- **KPIの変数の既定が「（実績を数えない）」。** そのまま足すと目標だけが残り、
  実績が永久に出ない。メモだけのKPIを許すための既定なので、変えるかは判断が要る。
- **終わった期に後から積んだ記録は、ファネルに出ない。** 2期の基準日は
  選考終了日（2026-04-15）で、今日書いた通過はその断面に入らない。
  「最終面接 1件通過」なのに「合格 0人」と並ぶ。**日次断面と累計の混在**である。
  設計意図（過去の断面を動かさない）どおりだが、同じ画面に並ぶと矛盾に見える。

### パイロットの仕込みで直したこと（道具側）

「人を探す」の合計15と食い違った ―― **画面の欠陥ではなく仕込みの欠陥。**
