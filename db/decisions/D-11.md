### D-11. 段の語が再定義された。実装はまだ追随していない ★未実装

2026-08-07（実行⑤）に、上位文書として `director.md`（憲法）と `domain.md`
（世界設定）が置かれた。`domain.md` はトポロジー（構造）とワークフロー（イベント）と
リレーションシップ（関係）を3つの軸に分け、比喩語を**エンティティの階層**として
定義し直した。**選考ステータスではない。**

その結果、実装済みの4語すべてが意味を変えた。

| 語 | 実装（いま動いているもの） | `domain.md` の定義 | 変化 |
|---|---|---|---|
| 森 | `partner_reaches` = 推定リーチ | Forest = 生態系の実体 | 接触機会 → 実体（リーチは属性へ降りる） |
| 林 | `identified_person` = 直近90日に接点がある**人** | Community = 森の中の**組織** | **人 → 組織** |
| 木 | `applicant` = **応募** | Person = **個人** | **応募 → 人** |
| 幹 | `accepted` = 合格した**応募** | （未決。Member は Membership から導出） | 応募 → 未決 |
| 純幹 | 辞退控除後の合格 | 対応語なし | — |

コード上の出現数（2026-08-07 実測）——
`林 94 / 木 60 / 幹 49 / 森 23 / 純幹 8` の計 174 箇所。

**実装は一切変えていない。** したがって現在のコードとビューは D-2
（「林は人、木と幹は応募」）のままで正しく、`domain.md` の定義とは食い違っている。

この食い違いを放置すると、実行③で踏んだ「同じ言葉が2つの定義を持つ」
（林が 2,576 対 661 になった件）の再演になる。移行するときは、
機械的な置換ではなく**旧ビューを非活性化して新しい語で作り直す**こと。

**未解決の項目は `domain.md` 10節にある**（`partner_relations` と Relationship の
語の衝突、Task の定義、Interested の判定事実、Forest / Community の実体、
Membership の粒度、実装段階の上書き可否、`director.md` の IA の重複）。

なお 2026-08-07 に MVP モードへの切替指示があり、Forest / Community / Person /
Task の4概念に凍結、Membership / Connector / Relationship 等は TODO(MVP) 送りとなった。
大規模な書き換えは行わず、既存構造の拡張を優先する。**この項目の解消は
MVP が動いた後になる。**
