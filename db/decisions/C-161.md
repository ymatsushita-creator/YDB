### C-161. ホームが枠を使い切っていなかった（依頼者の指示）

依頼者の言葉（実行⑯）――「ここ、面積しっかりつかって。あと、スクロールは
できないように。あと、上の横バーは固定して」。

#### 原因は2つ。どちらも「当てて書いた」ことだった

```
① 高さを 100vh から引き算していた
   .home-dashboard { height: calc(100vh - var(--logo-h) - 108px) }
   **108 は当て推量。** パンくずと見出しの実寸とは合わない ――
   余れば下に灰色が残り、足りなければ器ごと送れる（画面が縦にずれる）。

② カードの伸ばし方が、当たらない選択子だった
   .home-dashboard .panel-card { height: 100% }
   Card が出すのは `.card-base` である。**1つも当たっていなかった** ――
   だから中身の少ないカード（ピックアップ）だけが途中で切れ、
   その下に灰色の帯が残っていた（画面の右下だけが欠けて見える）。
```

★ ②は**画面を見れば分かる欠けだった。** 選択子を書いたときに、
  実際に当たっているかを見ていない。CSS は当たらなくても静かに通る。

#### 直したもの

```
高さ    残りを受け取る（flex: 1 1 0%）。数えるのをやめた
器      .hh-main:has(> .home-dashboard) { overflow: hidden } ―― 器は送らない
カード  .card-base を狙う。左右とも天井まで伸ばし、中だけが送る
数字の帯 104px で決め打ち（中身なりにすると余りがこちらへ流れて間延びする）
```

#### 実測（ブラウザで、3つの寸法で確かめた）

```
1280×700    送りなし／カード 348・348／下の余り 16px（器の余白のみ）
1440×900    送りなし／カード 548・548／下の余り 16px
1680×1200   送りなし／カード 848・848／下の余り 16px
```

★ 横バー（`.zoom-bar`）は元から `position: sticky; top: 0` だった。
  器が送らなくなったので、**固定であることが常に見える**ようになった。

検証: `tests/68_home_layout.test.ts` 5件（100vh の引き算をしない／器は送らない／
**カードは `.card-base` を狙う**／横バーは固定／図の高さが肥大していない）。
