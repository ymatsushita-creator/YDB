### C-66. ロゴが、2本のバーの寸法を決める

依頼者の指示（実行⑩）――「Neoアカデミアのロゴの縦と横の長さと、
縦バーと横バーの長さを合わせてみて」。

```
ロゴの横 204px  =  縦バー（操作柱）の幅
ロゴの縦  81px  =  横バー（現在地の帯）の高さ
```

ロゴ枠は縦バーの内側の余白を突き抜けて**左上の角いっぱい**に置く。
そこから下へ縦バーが、右へ横バーが伸びる形になる。
角丸も縦バーに合わせた ―― ここだけ丸みが違うと、貼り付けた別物に見える。

#### 縦は目分量で置かない。画像の実寸から導く

`public/brand/logo_black.png` は **1274 × 404**（比 3.1535）。

```
枠の横 204 − 余白 12×2 = 画像 180
画像の縦 = 180 ÷ 3.1535 = 57.08
枠の縦   = 57.08 + 12×2 = 81.08  →  81px
```

**画像を差し替えたらこの計算をやり直す。**
実行⑨で取り消したアニメーション（C-59 として一度入れて戻したもの）では、
目分量の 236×106 を使って**ロゴが外側から生えて見えた。**

値は `--logo-w` / `--logo-h` / `--logo-pad` の3つに置いた。
縦バーの幅も横バーの高さもこれを参照するので、**1箇所直せば両方動く。**

#### 縦バーが 236 → 204 に狭まった

ロゴに合わせた結果である。中身（タブ・検索・期の切替）は
はみ出していないことを DOM で確かめた。右の中身は 32px 広くなった。

#### ★ 高さを指定しても、flex は縮める

`.zoom-bar` に `height` だけを与えたら、**送る画面（選考オペレーション・
人を探すなど）でだけ 81 → 58 に潰れていた。** `.hh-main` は縦の flex で、
flex item は既定（`flex-shrink: 1`）で縮む。`flex: 0 0 auto` を添えて直した。

**「指定したのに効かない」は、たいてい別の軸が効いている。**

#### 確かめ方

14経路すべてで、次の4つが成り立つことを DOM で数えた。

```
ロゴの横 = 縦バーの幅         14/14
ロゴの縦 = 横バーの高さ       14/14
ロゴの左上 = 縦バーの左上     14/14
ロゴの下端 = 横バーの下端     14/14
はみ出して送れない要素         0 件
```
