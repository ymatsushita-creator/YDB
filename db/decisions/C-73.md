### C-73. 配色を変えたら、その上の文字を測り直す

依頼者の指摘 ――「ここ読めるようにして。見づらい」。

現在地の段（`.zoom-crumb-current`）が**黒地に黒文字**になっていた。
面を黒にした（`--color-primary`）のに、文字色 `#111` の指定が
より高い詳細度で残っていたためである。前は面が灰だったので読めていた。

**面の色を変えたら、その上の文字を必ず測り直す。**

#### 灰の補助文字も届いていなかった

白黒にしたときの灰が明るいまま残っており、カードの地やページの地の上で
コントラスト比 2.5〜4.1 しかなかった（本文の基準は 4.5）。

目分量で暗くしていない。**いちばん暗い地（`#e9e9e9`）の上で 4.5 を満たす、
もっとも明るい灰**を計算して置いた。

```
steel  #767676 → #696969   地 3.74 → 4.52
stone  #959595 → #6b6b6b   白 3.00 → 5.31
link   #0b7ea4 → #096a8a   地 3.81 → 5.03   ★色相は変えていない。濃さだけ
```

★ 1つ踏んだ ―― `--color-star-on` を白地用に暗くしたら、
**暗い操作柱の上に乗るデモの断り書きだけが読めなくなった。**
**同じトークンを、明るい地と暗い地の両方で使わない。**

#### 確かめ方

16経路で、**文字を直接持つ要素すべて**のコントラスト比を計算し、
本文 4.5・大きな文字 3.0 の基準に届かないものを数えた。

```
直す前   1000 件超
直した後 0 件
```
