### C-137. 残った面積をランキングに渡した（依頼者の指示）

依頼者（実行⑮）――「**ランキング表で使って残り面積使って**」。

C-136 で特別選考から「やること」を外したら、**画面の下半分が灰色の余白**に
なった。原因は列の割り付けである ――

```
.hh-col-main { grid-template-rows: minmax(0, 0.6fr) minmax(0, 1.4fr) }
                                   ↑ やること      ↑ ランキング
```

**上下2枚を前提にした比率**なので、上を外すとランキングが 0.6 の行に入り、
**1.4 の行が空いたまま残る。** カードを消したのに、カードが居た場所は残っていた。

#### 直したもの

```
1枚だけの列   その1枚へ**高さを全部渡す**（:has(> :only-child) で 1fr）
ランキングの行 中身なりをやめる（grid-auto-rows: minmax(0, 1fr)）――
              中身なりだと**背の高いほうの高さで止まり**、片方が空のときに
              下へ余りが出る。狭くて2段に折り返したときも等分に割る
```

★ **枚数を数えるのは CSS の仕事にした。** 画面ごとに「1枚のとき用」の
クラスを足すと、次に1枚減ったときにまた余白が出る。

★ `.hh-rankings` の規則が**2箇所に分かれていた**（458行目と割り付けの節）ので、
1箇所へまとめた ―― 同じ性質を2箇所で決めると、後ろの層が黙って戻す
（`.zoom-bar` の `position` で踏んだのと同じ穴）。

#### 測った（主領域 1100px ・ 高さ 760px）

```
列の高さ     760px ／ カード 760px × 2枚（左右）／ **下の余り 0**
表           カードの中で送れる（見えている 679px、39行で溢れる）
片方が空     空のカードも同じ高さに伸びる（背の高いほうに合わせない）
```
