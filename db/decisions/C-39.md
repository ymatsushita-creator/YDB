衝突の中身はこうだった ―― 上位文書の `design.md` は「Soft green / Calm /
Spacious」を要求するが、実際にトークンを生成しているのは
`basic/DESIGN.md`（NEO ACADEMIA ブランド）で、その最重要原則は
**「色は線、面は黒」**だった。だから面に使うトークン（`primary` /
`brand-navy` / `card-tint-*`）は全部白か黒に倒してあり、
**アクセント色の面塗りが構造的に作れなかった。**

実行⑨で届いた画面画像は、オレンジの面塗り・白いカード・柔らかい影を

**依頼者の判断は「画像を正典にする」**だった。

#### 何を変えたか

`basic/DESIGN.md` の frontmatter を書き替え、`pnpm tokens` で再生成した。
**トークン名は1つも変えていない。** 既存9画面が `primary` /
`card-tint-*` / `brand-navy` を参照しており、名前ごと入れ替えると
意匠の変更が全画面の改修になる。どこが意図した変更で、どこが事故なのかを
区別できなくなるので、**名前は器として残し、値と役割だけ入れ替えた。**

足したトークンは、画像にあって既存の部品では表せなかったものだけ ――
`shell`（カードを浮かせる地）、`sidebar-*`、`crest-gold`、`rank-up` /
`rank-down`、`star-on` / `star-off`、そして部品として
`sidebar-region` / `zoom-bar` / `panel-card` / `chip-*`。

#### 本文（散文）も書き替えた

frontmatter だけ直して本文を残すと、**文書のほうが嘘になる。**
「紫の CTA」「ネイビーの hero band」と書かれた Notion の分析が
そのまま残っていると、次に読む人がそれを設計意図だと受け取る。
`## Overview` / `## Colors` / `## Do's and Don'ts` を画像の説明に置き替えた。
`## Typography` / `## Layout` / `## Shapes` は内容が変わらないので残した。
