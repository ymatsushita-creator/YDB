#### ★ 空欄24人を、どちらにも寄せない

左端は3状態ある（TRUE / FALSE / 空）。指示が名指ししたのは2つだけである。
空欄を「TRUE ではないから2期」と丸めれば、**表に無い値を作ったことになる**
（CLAUDE.md「記録にない値の創作」）。

```
cohort: 2 | 3 | null      null は「表が決めていない」
```

`null` の人には**期にぶら下がる行を1つも書かない**（候補者番号・アプローチ状態）。
人とメモは人にぶら下がるので残す。取り込みの出力に人数を出し、
**決まっていないことが毎回見えるようにする。**
