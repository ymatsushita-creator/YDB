### C-117. 縦タブと横タブを1枚の帯にし、評価軸は動かさず全件を出す

依頼者の指示（実行⑬）――「横タブと縦タブは結合して同じレイヤーにしろ。幅が違う。
あと、評価軸は動かさなくていいので全部入るように」。

★ **厚みの違いは「潰れ」だった。** ロゴ枠は `--logo-h`（67px）を指定しているのに、
縦バーが縦の flex なので既定（`flex-shrink: 1`）で **67 → 24 まで潰れていた。**
`flex: 0 0 auto` を与えて止めた。送る画面の操作柱が 81 → 58 に潰れた C-66、
評価基準の枠が見出しだけになった C-113 と**同じ形が3度目**である。
★ 高さを指定した枠には、`flex: 0 0 auto` を必ず添える。

★ **天端も 16px ずれていた。** 縦バーは `position: sticky; top: var(--space-md)` で、
`top` は枠の余白の内側から測られるため、余白ぶんさらに下がっていた。`top: 0` にした。
実測で 天端16・厚み67・右端220で接続・下端83 ―― 4つとも一致。

★ 評価軸は**流すのをやめた**（依頼者の指示）。流れているものは狙って読めない。
折り返して全件を同時に出す（11軸・見切れ0・送り0で実測）。
流していた頃は同じ並びを2組出してつないでいたが、止めた以上そのぶんは重複なので1組にした。
`prefers-reduced-motion` の分岐も落とした ―― **減らす動きが無い。**

#### ★ 縦バーの足元が 60px はみ出して、出る手段が画面から消えていた

期の切り替え・デモ札・**「出る」ボタン**が枠の外にあり、押せなかった。
縦バーごと送るとロゴまで流れて帯がそこで切れるので、**送るのはタブの並びだけ**にした
（ロゴと足元は動かさない）。C-113 で操作柱に対して行ったのと同じ手当て。
