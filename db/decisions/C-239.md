## C-239 YouthDBを「playful operations」へ刷新した

**2026-09-09。依頼者の指示** ―― 別プロダクト用のNEO CAMPUSデザインを
YouthDBに合わせて直し、そのデザインでYouthDBのUIを一新する。

### 何を持ち込み、何を持ち込まなかったか

NEO CAMPUSの「静かな基盤＋行動を促す明るい層」と、太い輪郭・硬い影による
操作の手触りを採った。一方で、YouthDBは人の選考を扱う運営コックピットなので、
クエスト・XP・ランク・報酬・キャラクターなどのゲーム表現は採らない。

色の役割は次へ固定した。

| 役割 | 色 |
|---|---|
| 現在地 | ピンク |
| 主操作 | 黄色 |
| 情報・検索 | 空色 |
| 完了・合格 | ミント |
| AI・特別機能 | 紫 |
| 個人情報・表・入力 | クリームの地と白い紙面 |

### 実装

意匠の正典 `basic/DESIGN.md` をYouthDB用の
`YouthDB-playful-operations-design-system`へ更新し、`pnpm tokens`で
`app/tokens.css`を再生成した。`app/_styles/01〜06`の責務と取り込み順は変えず、
foundation / shell / controls / tables / forms / cards の各層で新トークンを描画した。

Server Componentとデータ取得、権限判定、URL、書き込み処理は変更していない。
React側は、旧Googleブルー系の直値を意味トークンへ寄せ、自動保存の表示を
インラインstyleから状態クラスへ移しただけである。

### 硬い影を使う範囲

硬い影は、主ボタン、現在地、選択中タブ、ホームの遷移可能な数値カード、
人物の主要見出し、ダイアログに限る。表、入力値、長文、通常カードには使わない。
候補者をゲームの対象に見せず、操作可能性だけを明るくするためである。
