### C-68. 横バーを、ロゴの右端から続けた

依頼者の指示（実行⑩）――「横バーもつなげてみて」。

C-66 でロゴと2本のバーの寸法を揃えたが、**ロゴの右端と横バーの左端の間に
16px の隙間が残っていた**（列の隙間 `--space-md`）。
横バーを同じぶんだけ左へ引き戻して、隙間を 0 にした。

```
ロゴの右端 220px  =  横バーの左端
```

着いた側の角は落とし、左のふちも消した ――
**丸いままだと、くっついているのに切れ目が入って見える。**

#### 狭い画面では、つなぐ相手が居ない

760px 以下では縦バーが上へ回る（1列になる）。引き戻しをそのままにすると、
**帯だけが画面の外へはみ出す。** その幅では引き戻しを戻し、角も丸に戻す。

#### `/applications/[id]` にだけ帯が無かった

つながりを14経路で測って気づいた。**この画面にだけ現在地の帯が無く**、
いま何を開いているかも、上へ戻る道も出ていなかった
（本文に手書きのパンくずがあっただけ）。

帯を足し、本文の手書きは消した。**同じものを2箇所に置かない。**

```
2期 › ボーダーライン › 柏木 朔 › 応募
```

氏名は採点レイヤー（C-63）へ戻る。期の呼び名は `seasonLabel` に任せる ――
画面ごとに「2期」「2026年度」と呼び分けない。
そのために `getApplication` へ `cohort_number` を足した。

#### 確かめ方

14経路 × 幅 1280 / 1000 / 700 で、
**つながり・高さ・幅・上端の4つが一致**することを DOM で数えた。
