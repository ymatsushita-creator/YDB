#### ★ 開いたままの穴を、開いたままだと書く

**2つの共有合言葉では「誰が入ったか」は記録できない**（C-84 の穴はそのまま）。
表の「入力者」もメモの「書いた人」も**自己申告のまま**である。
記録に残るのは「共有で入った・誰か分からない」だけ。
**依頼者はそれでよいと判断した。こちらはその判断を、穴と一緒に記録する。**

#### 配るのは2つ

```
経営層    YOUTHDB_PASSWORD            → all（特別選考まで）
平社員    YOUTHDB_PASSWORD2           → personal（通常選考・面接まで）
入力層    YOUTHDB_PASSWORD_INPUT      **設定しない** → その層では誰も入れない（既定で閉じる）
```

★ コードは要らない。**設定を2つ置くだけ**である（0038 の前からそうだった）。
