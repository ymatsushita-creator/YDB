### C-127. 確度の軸は**定まっていない** ―― 画面が記録に無い格付けを名乗っていた

依頼者の指示（実行⑭）――「確度の軸が定まり、エクセルファイルと同じ基準で
判断され、混乱する用語がないか」。**3つとも問題があった。**

#### ① 軸は定まっていない（本番の規則は0件）

```
記録層   規則から点を積んで**比率（0〜1）**にする（0017）。★本番の規則は0件
運営     応募管理表 003_2期生アプローチリスト の「参加確度」――
         **帯（020％／050％／080％／100％）**と状態語
         （未計測72 ・ 興味なし/対象外183 ・ 応募完了53 ・ 帯 020%=46/050%=32/080%=32/100%=14）
```

★ **同じ基準ではない。** こちらは比率、運営は帯と状態語である。
帯を受け取って取り込むまで、確度は誰にも付かない（＝画面に出す数が無い）。
**取り込むかどうかは依頼者の判断**（マスタを増やす話であり、こちらで名付けない）。

★ 列16「ヨミ」も未取り込みである（帯と別の語で、意味を確認していない）。

#### ② 画面が「確度A以上」と名乗っていた ―― ★混乱する用語

ホームの系列とタイルが **「通常選考者（確度A以上）」「通常選考 A以上」** と
出していた。**A は記録のどこにも無い。**
さらに応募管理表では **A〜C（必須）・D〜I（加点）が特別選考の軸の記号**であり、
**同じ字が別の意味**で画面に出ていた。閾値 0.8 も受領していない（0017 は
「点数と閾値は運用時に決定」と書いて空で出荷している）。

```
直した   ラベルは「確度の高い候補者」。**記録に無い格付けを名乗らせない**
         閾値は画面に書かない（C-62）。由来はクエリのコメントと本項に置く
         フィールド名も regular_a → high_confidence（A を持ち込まない）
```

#### ③ 規則が無いとき、0 を出さない

規則が0件なら確度は算出されない。**それを 0 と出すのは嘘である**
（0017 が「無いことを 0 と書くと、それは嘘の数字になる」と書いた形）。
ホームは規則が無ければ**確度の線を引かず**、タイルは「算出なし」を出す。

検証: `tests/57_confidence_axis.test.ts`（本番シードに規則が無い／規則が無ければ
算出なしで出る／**「確度A」を画面へ戻さない**／閾値を画面に書かない／
受領していない格付けの語が画面に無い）。本番の規則数は読み取りだけで数えた。
