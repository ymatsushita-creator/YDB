### C-90. 横バーと縦バーを1つの面にし、ロゴとの接合を四角にした

依頼者の指示（実行⑪）――「横バーと縦バーは結合して」「ロゴと横バーの
接合部分はまるでなくて四角で接するようにして」。

C-68 で幾何は接していた（横バーの左端＝縦バーの右端）。それでも2枚に見えていた。
**接していることと、1つに見えることは別である。**

|      | 直す前 | 直した後 |
|---|---|---|
| 面 | 横バー `#111` / 縦バー `--color-brand-navy` | 同じ `--color-brand-navy` |
| ふち | 横バーだけ 1px の黒 | 持たない（縦バーに合わせる） |
| 影 | 横バーだけ外側へ落としていた | 落とさない |
| 角丸 | 横バー 12px / 縦バー 16px | どちらも `--rounded-xl`（16px） |
| ロゴの右上 | 12px の丸 | **0（四角）** |

ロゴの右上を丸めていたのが、いちばん効いていた。丸めると、ロゴと横バーの間に
**地の色の三日月**が残る ―― 触れているのに切れて見える。外へ向いた角（左上）
だけを丸め、続きになる側は四角で突き合わせる。

ロゴから伸びる線（brand.css）の右下の丸みも、バー本体と同じ値に直した。
ここだけ 12px のままだと、線が角の外へ 4px はみ出す。

実測（画面で確認）: 面が一致 / 横の隙間 0px / 下端の差 0px /
ロゴ右上・横バー左上左下の丸み 0px / 横バーのふちと影なし。
