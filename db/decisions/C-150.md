### C-150. 一覧の名前で画面を飛ばさない。確度ランキングを外す（依頼者の指示）

依頼者の言葉（実行⑯）――「名前押したらその個人画面に行くんじゃなくて、
**個々の画面に出せ**って言ってんだろ。**ここに詳細ボタンをおいてそこから行け**
って言ってただろうが」。

#### 直したもの

```
欲しい人ランキング  名前 → 右のパネルに出す（?person=）。人の画面へは「詳細」から
特別選考リスト      「›」だけの的を「詳細」の語に変えた
```

★ 特別選考リストは**元からこの形だった**（名前＝パネル、`›`＝人の画面）。
ランキングだけが名前で飛んでいた。**同じ画面の中で挙動が2種類あった**のが
そもそもの誤りで、依頼者はそれを2度指摘している。

★ `›` は「何が起きるか読めない印」である。語を出す。

#### 外したもの ―― 候補者確度ランキング

依頼者の言葉 ――「ここもいらねぇんだよ。その代わり、応募者ランキングと
選択者画面と特別選考リストの面積でかくしろよ」。

規則が1件も無いので、この枠は**ずっと「確度の算出規則が未登録」だけを出していた。**
枠ごと外し、面積を3つへ渡す。

```
右列の幅       340px → 420px（狭いほうを広げる。12項目＋記入欄が入る）
右列の比率     0.85/1.15 → 1/1（日程カレンダーが下にあった頃の割り付けを直す）
左列           2枚 → 1枚。`.hh-rankings` が枚数で割り付けを変える（C-137）
```

★ 出さないものは**問い合わせもしない。** 確度の順位・算出規則・アプローチ集計の
3本が消え、この画面の往復は5本から3本になった。
