### C-140. ★★ 帯の高さを黒バーの真ん中に揃えた ―― **基準点が無かった**

依頼者（実行⑮）――「**高さを真ん中に揃えて**」。

C-135 で「縦は1px差で揃っている」と報告したが、**依頼者の画面ではずれていた。**
測ったのは**こちらが作った再現の頁**であって、本番の入れ子ではなかった。

#### 何が起きていたか

```
.hh-criteria-ref   position: absolute; top: 0;
.hh-main           **位置指定を持っていなかった**
.hh-frame          padding: var(--space-md)
```

基準点（`position` を持つ祖先）が無いと、`absolute` は**画面そのもの**を基準にする。
`top: 0` は画面の上端であり、黒バーは `.hh-frame` の余白ぶん下から始まる ――

```
黒バー   上端 32px ／ 高さ 67px ／ 中心 66px
帯       上端  0px ／ 高さ 67px ／ 文字の中心 33px   ★ 33px 上にいた
```

**ずれ幅は `--space-md`（32px）そのもの**で、外枠の余白と一致する。
`.hh-main` に `position: relative` を置いて、基準点を**黒バーと同じ箱**にした。

```
直したあと   帯の上端 32px（黒バーと一致）／ 文字の中心 65px ／ バーの中心 66px
```

#### ★★ 確かめる頁は、本番と**同じ入れ子**で作る

C-135 で作った再現の頁は、帯を `position: relative` の箱の中へ直接置いていた。
**基準点を写していなかったので、ずれが再現しなかった。**
再現の頁は本番より条件が甘くなりがちで、**甘いほうで測ると「揃っている」と
書いてしまう。** 今回は `.hh-frame` から組んで、位置指定を外した状態と
付けた状態の**両方**を測って差（32px）を出した。

見張りは `.hh-main` の `position: relative` を固定する ―― これは**帯のための
指定**であって、消すと帯が黙って上へ戻る（理由をCSSにも書いた）。
