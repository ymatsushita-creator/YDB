### C-72. 「箱は接しているのに、絵が離れる」

依頼者の指摘 ――「ここつながってねぇって言ってんだろ」。

C-68 で横バーをロゴの右端へ着けた。`getBoundingClientRect()` は
**どの幅でも隙間 0** を返していた。**それでも画面では離れていた。**

原因 ―― 列の隙間（`--space-md`）をマイナスマージンで打ち消していたが、
`.hh-main` は `overflow: hidden`（一覧の画面では送る器）なので、
**親の外へはみ出した 16px が描画で切り取られていた。**
箱の計算では接し、絵では離れる。

直し方 ―― 列の隙間そのものを 0 にし、`.hh-main` の**内側**に余白を持たせ、
横バーだけがその余白を打ち消す。こうすると横バーは
**親の中に収まったまま**左端へ着くので、切り取られない。

#### ★ 測り方を変えた

箱で測るのをやめ、**実際に描かれているもの**で測るようにした ――
`elementFromPoint(ロゴの右端 + 1px, 帯の中心)` が横バーを返すか。

```
箱で測る      隙間 0        ← 通っていた（が、画面は離れていた）
描画で測る    右隣は横バー   ← いま通っている
```

**「はみ出しているか」ではなく「そこに何が描かれているか」を見る。**
