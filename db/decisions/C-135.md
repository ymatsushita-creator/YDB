### C-135. 帯の字をもう一段大きくした（13px → 16px。依頼者の指示）

依頼者（実行⑮。デプロイ直後）――「**横バーの評価軸の文字が小さい。
あと真ん中に揃えて、横スクロールして**」。

★ **同じ3点が2度目である**（1度目は C-128）。1度目のときは 10px → 13px にした。
**まだ小さいと言われた**ので 16px にした。帯の高さ（67px）に対して1行 19px
なので、まだ余裕がある。

#### 真ん中と横送りは、**すでにそうなっている**（測り直した）

1060px の主領域（1280 の画面から左の縦バーを引いた残り）で測った ――

```
字        16px
縦        帯の中心 34px ／ 文字の中心 33px ―― **1px 差**（行箱の丸め）。縦の溢れ 0
横        送れる幅 2430px ／ 見えている幅 615px。**送れる**
届く      右端まで送ると最後の軸の右端が帯の右端に一致。
          左端まで戻すと最初の軸の左端が帯の左端に一致（掴めない領域は無い）
```

★ **横方向の「真ん中」は、収まるときだけ効く**（`justify-content: safe center`）。
15軸は 2430px あって 615px には収まらないので、**中央寄せのままだと左端が
掴めなくなる** ―― `safe` はそこで先頭寄せへ落とす。溢れているものを中央に
置くことはできない。ここは物理の話なので、指示に反しているのではなく
**指示が両立しない**場所である。

★ 一度は「送り帯（スクロールバー）が下端を食って中心がずれる」と考えて
`padding-top` で補正したが、**測ったら食っていなかった**（macOS の重ね表示の
スクロールバーは場所を取らない）。補正のほうが 3px 下へずらしていたので、
**入れた補正を測って取り消した。** 見ないで足した手当ては、たいてい害になる。
