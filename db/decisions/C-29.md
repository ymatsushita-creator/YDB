### C-29. ロゴとパレットを NEO ACADEMIA ブランドに差し替えた

実行⑦。2026-08-07。**依頼者の指示で、保留していた生成元が決まった。**

これまで `app/tokens.css` は `basic/DESIGN.md`（Notion のブランド分析）から
生成されており、`design.md` は soft green を求めていた。**生成元が未決**だったため
「画像から色を起こして推測で埋めない」を守って触っていなかった（HANDOFF 7節）。
指示によりこの保留が解けた。

#### 推測していない

色は**ブランド規定に書かれた値をそのまま置いた。** ロゴ画像から色を吸ったのではない。

```
ネオンイエロー #F0F000 / ネオンピンク #F03090
ネオンシアン   #00C0F0 / ネオングリーン #50F000 / ネオンレッド #F01010
ベース         白 #FFFFFF / 黒 #0A0A0A / グレー #707070 / 罫線 #E5E5E5
```

**★ 派生させた値が6つある。** ネオン色は白背景の文字として読めない
（`#F0F000` は特に）。規定の色相を保ったまま暗くしたものを、
`link-blue` / `link-blue-pressed` / `brand-orange-deep` /
`semantic-success` / `semantic-warning` / `semantic-error` に当てた。
**`DESIGN.md` の中で ★ 印を付けて、規定の値と区別できるようにしてある。**

#### 「色は線、面は黒」をトークンの側で強制した

ブランドの最重要原則である。**面をアクセント色で塗らない。**

そこで**面に使われるトークンを全部、白か黒か極薄のグレーに倒した。**

- `primary` / `brand-navy` / `brand-purple*` → 黒（塗ってよい唯一の色）
- `card-tint-*`（9個の淡色）→ 白と極薄グレー

これで CSS 側を1行も直さなくても、**アクセント色の面塗りが構造的に作れなくなる。**
以後 `card-tint-*` を背景に使っても色は出ない。

#### 色を消したら一覧が読めなくなった ―― 面から線へ移した

淡色の面塗りを消した結果、**やることの種別が全部ただの黒文字になった。**
色を消すのではなく面から線へ移すのが規定の意図なので、
`app/base.css` の末尾でバッジを塗りから**左の2px 線**へ組み替えた。

```
評価する      シアン      担当を替える  ピンク
担当を決める  イエロー    保留を解く    グレー（停止状態なので色を当てない）
```

規定のグラフ系列順（シアン → ピンク → イエロー → グリーン）に合わせてある。

選択中の行も淡い面だったので、**黒い線**に変えた。期限超過（赤）とは別の辺を
使うので、両方立っても打ち消し合わない。

#### ロゴ

ブランド名は**必ずロゴ画像で出す。** 極太テキストで「NEO ACADEMIA」と書くと
ロゴと競合する（規定）。`Youth<span>DB</span>` のワードマークを
`public/brand/logo_black.png` に置き換えた。比 3.15:1 を崩さないよう
`width` だけ与えて `height: auto` にしてある。白版も
`public/brand/logo_white.png` に入れてある（黒背景で使う）。
