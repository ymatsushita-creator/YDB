### C-71. 編集を深い層へ出し、面接をタブに上げ、ロゴと配色を差し替えた

依頼者の指示（実行⑩）。3つ。

#### ① 小さなパネルから編集させない

プロフィールの編集は、ヘッドハンティングの**右パネル（幅 340px）**に
12項目のフォームを `<details>` で畳んで入れていた。
書く場所として狭すぎるし、一覧を見ながら書くものでもない。

**深い層に出した** ―― `/people/{id}/edit`。
一覧の側には「プロフィールを編集 ›」の入口だけを残す。
アクションは既存のものをそのまま使う。**入口を増やしても規則は1つ。**
保存後の戻り先も編集画面にした ―― 一覧へ戻すと、書いた結果がその場で見られない。

#### ② 面接をタブに上げた（アプローチの下）

操作柱のタブが3つから**4つ**になった。
`/interviews` はその期の面接をすべて並べ、1枚ずつシートへ入る。

**段で絞らない。** 面接の一覧は選考の一覧ではない。
書いた／書いていないの区別なく並べ、**まだ書いていないものを先に出す** ――
書き終えたシートは読み返す用で、急ぐのは空いているシートである。

#### ③ ロゴをグラデーション版にし、配色を合わせた

```
public/brand/logo_gradient.png   1283 × 305（比 4.2066）
```

比が 3.15 → 4.21 に変わったので、**`--logo-h` を 81 → 67 に計算し直した**
（C-66 の式をそのまま使う）。縦バーの幅と横バーの高さも一緒に動く。

配色の出どころは2つで、どちらも創作していない ――
ロゴから実測した色と、NEO ACADEMIA の意匠規定
（ネオンイエロー `#F0F000` / ピンク `#F03090` / シアン `#00C0F0` / グリーン `#50F000`）。

★★ 原則は **「色は線、面は黒」**。★★
アクセントで面を塗らない。塗ってよい面は白と黒だけである。
そのため**白黒の土台（`monochrome.css`）は外していない。**
`brand.css` を1枚重ね、**線と文字と印だけ**を色にした。

```
tokens.css      原典から生成（触らない）
monochrome.css  白黒の土台
brand.css       線と文字の色 ＋ ロゴから伸びるグラデーション線
```

**brand.css を外せば白黒に、2枚とも外せば元の色に戻る。**

ロゴの下端から横バーの下端へ、**同じ1本のグラデーション線**を通した。
寸法を揃えてある（C-66 / C-68）ので、線はロゴの左端から画面の右端まで
途切れずに走る。
