### C-58. セクションの位置を、中身に関わらず固定した

実行⑨。依頼者から**同じ指示が2度**出た ――
「やることと確度順候補リストは独立させて。最新やることと成績ランキングも
独立させて。**各セクションの位置は固定して。**」

C-57 で「カードごとに送る」までは直したが、**位置は固定できていなかった。**
カードの高さが中身なりだったので、**やることが1件増えただけで下のカードが
動く。** 読む場所が毎回変わる。

#### flex ではなく grid にした

flex は子の伸縮が中身の高さに引きずられる。
**列を比率で割り付けて境目を固定する。**

```css
.hh-col-main { grid-template-rows: minmax(0, 0.8fr)  minmax(0, 1.2fr); }
.hh-col-side { grid-template-rows: minmax(0, 1.25fr) minmax(0, 0.75fr); }
```

`minmax(0, Nfr)` は「中身がどれだけ高くても、この比率に収める」。
**左右で必要な高さが違う**ので比率は列ごとに変えたが、
「中身に関わらず固定」であることは同じである。

#### 実際に固定されたことを、数で確かめた

|  | 上のカード | 下のカード |
|---|---|---|
| 2期（データあり） | top 90 | top 436 |
| 3期（データ0件） | top 90 | top 436 |

**中身が空でも位置が同じ。** 目で見ずに `getBoundingClientRect()` で測った。

#### 固定した副作用を1つ踏んだ

候補者パネルの高さが固定になった結果、**中身が入りきらず「基本情報」の
見出しだけが残った。** 編集欄が送る器の外にあって、器のほうが潰されていた。
編集欄も同じ器に入れ、右列の比率を上げて直した。

**縮ませる場所と、送る器の範囲は必ず一致させる。**
一致していないと、潰れるか、はみ出して重なるかのどちらかになる。
