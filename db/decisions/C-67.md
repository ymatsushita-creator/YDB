### C-67. 集計の但し書きを、画面から消した

依頼者の指摘（実行⑩）――「この説明文も消して」。

C-62 で説明を消したとき、**`callout`（帯）に入っていたものを見落としていた。**
枠が違うだけで、書いてあるのは同じ「集計の但し書き」である。

消したもの ――

```
どの期にも属さない接点が N 件（N 人）。期の期間外に起きたため、上の表には数えていない
年度に紐づかない団体リーチが N 件（推定 N）ある。どの年度の表にも出ないため…
推定リーチと識別済みの人数は単位が違うので、割って率にはしない
無効化理由に代替の応募が生まれないため、応募が起きた事実として集計する
```

画面から消しただけで、そのためだけに引いていた問い合わせ
（`getUnattributedTouchpoints`）も一緒に落とした。
**出さない値を引き続けない。**

無効化の帯は事実だけ残した ―― `2026/04/01 12:00 無効化（名寄せ誤り）`。
集計に数えるかどうかは、隣のバッジ（`集計対象外`）がすでに出している。

★ 残したもの ―― 選考オペレーションの
`3 件が SLA を超えて止まっている。最長は 32 日（書類選考）。`
**これは集計の説明ではなく、いま起きていることの報せである。**
消すと「最長何日か」がどこにも無くなる。

#### 見落としの型

「説明を消す」を `unit-note` / `footnote` / `note` の**クラス名で探した**ので、
`callout` に入っていたものが残った。**枠ではなく中身で探す。**
