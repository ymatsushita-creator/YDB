### C-128. 評価基準の帯を、真ん中・大きめ・横送りにした（依頼者の指示）

依頼者の指示（実行⑭）――「ちょっとみためが悪いから直して」→
**「真ん中配置、文字大きめ、横スクロールにして」。**

#### 何が悪かったのか（送られた画面から読めたこと）

```
① **天端で1行目が切れていた** ―― 3期を2期にそろえて軸が15本になり（C-122）、
   帯の高さ（--logo-h = 67px）に折り返しが収まらなくなった。
   縦に送れる指定（overflow-y: auto）だったので、上へずれて必須の3本が読めない
② **通し番号 1〜15 が段をまたいでいた** ―― 9番までが特別選考、10番からが最終面接。
   **画面が勝手に作った番号**で、記録には無い（`{i + 1}`）
```

★ ①は「切れているものは読めないのと同じ」（C-65）の再演である。**軸が増える
ほうが先に来て、器の高さは変わらなかった。**

#### 直したもの

```
縦        1行に収め、**縦は真ん中**（align-items: center）。縦へは溢れさせない
横        入らないぶんは**横へ送る**（overflow-x: auto）。折り返しはやめた
          収まるときは中央（justify-content: safe center）
          ★ `safe` が無いと、溢れたときに**左端が掴めなくなる**
字        10px → **13px**（依頼者の指示。1行になって高さに余裕ができた）
番号      **やめた。** 記録に無い通し番号を画面で作らない
段の境目   **区切り線**で見せる ―― **見出しは出さない**（実行⑬の指示は生きている）
札        必須／加点に `flex: 0 0 auto` を添えた（高さを持つ枠。**4度目**。C-66/C-113）
```

★ **勝手には流さない**（実行⑬）。横へ送るのは利用者であって、画面が動くのではない。

#### 確かめ方 ―― 合言葉の内側は見ていない

帯は認証の内側にあり、**こちらは合言葉を入力しない**（proxy は鍵が無ければ
誰も通さない）。そこで**同じ CSS と同じ軸名で帯だけを再現した頁**を作って測った。

```
送れる幅 2371px ／ 見えている幅 760px（本番と同じ min(58%, 760px)）
帯の高さ 67px ／ 軸の高さ 17px ／ **縦の溢れ 0**（切れが消えた）
区切り線 1px rgba(255,255,255,.22) が段の間に出る
```

★ **見ていないものを見たと書かない。** 実データの画面は依頼者に見てもらう。

検証: `tests/45_home.test.ts`（1行に並べる／横へ送れる／縦へ溢れさせない／
縦は真ん中／`safe center`／字は13px以上／**画面が通し番号を作らない**）。
