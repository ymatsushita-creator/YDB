### C-151. 確度を、計算値から**記入値**へ（依頼者の指示）

依頼者の指示（実行⑯）――「確度の基準はこちらをもとに設計し、
**入力者が記入、加えていつでも編集できる**ように」。

```
S  イベント参加or2期説明会参加/3期応募口頭内諾
A  2026年イベント参加
B  2025年度イベント参加 / 応募したが落ちたor辞退/懸念事項がある/前回はやりたいことがあり断念
C  まだNEOイベント未参加/NEOに入ると良いと思う人
```

★ **文面はそのまま記録層に入れる**（`confidence_grades.definition`）。
要約も言い換えもしない。記入する人は、この文を画面で読んで選ぶ ――
**基準を畳んだ瞬間、記入は当てずっぽうになる。**

#### 「いつでも編集できる」を、上書きで満たさない

0039 は追記専用（0016 / 0035 と同じ形）。書き直すと `setConfidence` が
**前の記入を打ち消してから**新しい記入を足す。行は減らず、2行増える。
上書きにすると、いつ誰が見立てを変えたのかが残らない。

★ 期ごとに持つ。2期がSでも3期は未記入でいられる。人に現在値を1つ持たせると、
期を跨いだ瞬間に前の期の判断が消える。

★ 記入者は**手入力の自己申告**（0027 と同じ）。C-146 で共有の合言葉に戻ったので、
システムは誰が入ったかを知らない。**知らないものを知っているふりをしない。**

★ 0017 の導出確度（`score_snapshots.confidence_ratio`）は**残す**
（適用済みマイグレーションは編集しない）。規則が入ればいまでも動く。
**画面が見るのがこちらに変わった**だけである。
