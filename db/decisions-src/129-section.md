### C-80. デプロイ前に、追跡対象を実在個人情報で走査する

`git add -A` が2つを取り込んだ ――
**運営から受け取った `.xlsx`**（実在の応募管理表）と、
私が `openPglite(':memory:')` を実行して作った **38MB の一時ディレクトリ**。

どちらも push すれば公開される（`origin` も `mirror` も公開リポジトリ）。
即座に取り消し、`.gitignore` へ `*.xlsx` / `*.pptx` / `/:memory:/` を足した。

★ **`git add -A` を確かめずに打たない。**
運営から受け取った資料はリポジトリの直下に置かれることがある。

#### 走査を手順にした

コミット前に、**追跡対象になる全ファイル**を旧データの氏名・団体名と
`example.test` 以外のメールで突き合わせる。60 ファイルすべてで一致 0 件を
確認してからコミットした。**目で見て確かめない。**
