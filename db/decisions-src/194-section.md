### C-143. 配る画像を、表示の大きさに合わせた（軽くする）

依頼者の指示（実行⑮）――「軽くして」。**測ってから削った。**

```
タブのアイコン   /brand/logo_ydb.png    512×512 ・ 202KB  → icon_64.png     64×64 ・ 5KB
画面のロゴ       logo_gradient.png     1283×305 ・ 61KB  → _720.png       720×171 ・ 43KB
合計                                          263KB  →  48KB（**215KB 減・82%**）
```

★ タブは 16〜32px で描かれる。512px の原版を渡すのは、**表示の200倍のバイト数を
毎回配ること**である。画面のロゴも、出るのは最大 360px 幅（ログインの札）で、
原版は 1283px ―― **4倍**あった。

★ **意匠の資産は作り替えない・捨てない。** 小さい版を**足した**だけで、
原版（`logo_gradient.png` / `logo_ydb.png`）はそのまま残す（`basic/` と同じ扱い）。
`public/favicon.png`（202KB）と `logo_black` / `logo_white` は参照が無いが、
**受け取ったものを勝手に消さない。** 静的な置き物なので、要求されなければ配られない。
