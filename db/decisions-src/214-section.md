### C-163. 二次選考（グループ面接）の軸を入れた ―― **一度も作られていなかった**

依頼者の指示（実行⑯）――「二次選考の軸はこれだ」（最終面接の6軸を示して）
「じゃあ、最終と同じでいいから」。

#### これまで「決めていなかった」

依頼者の問い ――「今まで二次選考の軸はどう作ってきた？」。
答えは**作っていない**。0002 が理由を書いて空のまま置いていた ――

```
グループ面接の軸も入れていない。旧データに点が無い
（sec2_group は A〜E の組分けで、評価ではない）
```

軸の呼び名を受け取っていなかったので作らなかった。**受け取ったので入れた。**

#### ★ 0002 の判断に、読み方の食い違いがあった

旧システムの列は2種類 ――

```
sec2_score_smile / respect / premise / passion / thinking / honest   6軸の点
sec2_group                                                          A〜Eの組分け
```

**どちらも接頭辞は `sec2`（二次）である。** ところが 0002 は、
組分けの側は素直に「二次のもの」と読み、点の側は

> あの表は最終面接シートであり、列名の "sec2" は旧システムの呼び名にすぎない

として**最終面接の軸**に振った。**同じ接頭辞を、2つの列で逆向きに解釈している。**

依頼者の「二次選考の軸はこれだ」、列名 `sec2`、シート52で最終選考結果に
点が無いこと（合格・辞退・補欠だけ）―― **3つとも同じ方向を指す。**
0002 の判断は誤っていた可能性が高い。

#### それでも移し替えなかった

最終面接には **32件の評価・192点**が既にぶら下がっている（旧システムからの
取り込み）。**付いた点の所属を後から動かすのは、記録としてやってはいけない。**
同じ6軸を、グループ面接にも**別の行として**持たせた
（`evaluation_criteria` は段に属する。段が違えば別の軸である）。

直すなら訂正として履歴を残す形で、別途行う。

#### 入れ方（0008）

名前は**最終面接の軸から読む**（シートに書き写さない）。同じ語を2箇所に置くと、
片方を直したときもう片方が古くなる（0006 と同じ作法）。
既に軸があるグループ面接には触らない（冪等）。両期へ入れた。

```
特別選考     9軸36点
応募受付     0軸
書類選考     0軸  ★ まだ空
グループ面接  6軸24点  ← 0008
最終面接     6軸24点
```

#### ★ 書類選考は、まだ入れない

依頼者が「理想形としては、書類選考では、NEOとの相性／質問に論理的に
答えられているか／やり遂げた実績はあるか／コミットする意志があるか を
AIで自動分析させたい」と述べた。**4つで、満点16（＝4軸×4点）と数が合う。**

こちらは「その4つを軸名にしていいか」と尋ね、**依頼者は明確に否定した。**
AI に分析させたい観点として口にした言葉であって、運営の基準表の軸名ではない。

★ **思いつきの言葉をマスタに固定しない。** 0002 から一貫して守ってきた
（原則3：集計マスタは更新せず追加と非活性化で運用する）規律のとおり、
基準表の呼び名を受け取るまで空のままにする。
