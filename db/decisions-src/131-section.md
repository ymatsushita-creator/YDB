### C-82. 入口を閉じた ―― 合言葉1つ。**「誰が」はまだ記録できない**

依頼者の指示（実行⑩の終わり）――「合言葉1つで入れるようにして」。

C-81 が「実データを出すには ①認証 → ②`DATABASE_URL` → ③DBの分離」と書き、
**①を飛ばして②だけをやらない**と決めた。その①である。

```
proxy.ts              入口を1箇所で閉じる（Next 16。旧 middleware.ts）
src/auth/session.ts   合言葉の突き合わせと、署名した引換券
app/login/            合言葉を聞く画面と、入る・出る
tests/37_session.test.ts
```

#### ★★ これは認証の**半分**である

合言葉を全員で共有するので、**入った人を見分ける手段が無い。**
`docs/pilot/DEPLOY-READINESS.md` が求めるもののうち、満たすのは
**入口を閉じること**だけ。「誰がプロフィールを変えたか」は**まだ記録できない。**
残る課題から消さないこと。

#### 決めたこと

- **設定が無ければ、誰も入れない。** `YOUTHDB_SESSION_SECRET` が無いときに
  素通しする道を作らない。**閉じ忘れより、開き忘れのほうが取り返しがつかない**
- **画面ごとに閉じない。** 1枚でも書き忘れるとそこだけ開く。`proxy.ts` は
  全部の要求を通るので、閉じ忘れが起きない
- 通すのは `/login` と資材（`/_next` `/brand` `/favicon`）だけ。**中身の画面は0件**
- Cookie に合言葉を入れない。**署名した引換券**（中身は期限とその署名だけ）。
  端末に平文で残らない
- 署名を確かめてから期限を見る。逆にすると**期限だけ書き換えた偽の券**が
  「期限切れ」に混ざり、本物と偽物の区別が返り値から消える
- 失敗の理由を分けない（「合言葉が違う」だけ）。設定の有無まで外へ漏らさない
- 失敗のたびに 0.5 秒待つ。合言葉は1つで総当たりが効くが、
  **回数を数える置き場所がサーバレスに無い**ので時間で削る
- 戻り先は**自分のパスだけ**。`//example.com` を弾く（オープンリダイレクト）
- 合言葉そのものはリポジトリに書かない（`YOUTHDB_PASSWORD`）。**両リモートは公開**

#### 確かめ方 ―― 出しているものが閉じているかは、叩かないと分からない

C-60 と同じ穴である。単体テストは通っても、**経路が閉じている確認にはならない。**
`YOUTHDB_DEMO=1` と使い捨ての合言葉で本番ビルドを立て、18経路を未ログインで叩いた。

```
18 経路すべて 307 → /login（漏れ 0。`next` にパスだけが載る）
合言葉が違う → 「合言葉が違う」。戻り先は保たれる
正しい合言葉 → /headhunting へ入る（`next` を守る）
document.cookie から読めない（httpOnly）
「出る」→ /login へ戻る
```

**実データと実際の合言葉は使っていない**（デモDB・使い捨ての合言葉）。

場所**の印（C-47）で、`::before` が「記入できます」を出す。

どちらが規則でどちらが例外かを、理由付きで片方に寄せた。

#### ★★ 見張りが、漏洩経路になっていた

最初に書いた「合言葉がリポジトリに書かれていないか」のテストは、
**合言葉そのものを正規表現に持っていた。**

```
assert.equal(/（合言葉）/i.test(src), false, '合言葉が書かれている')
```

4つのソースは確かに綺麗になる。**そのテストファイル自身は見ていない。**
両リモートは公開なので、「これは合言葉である」という札付きで公開される
ところだった。push 前に気づいて履歴から消した（このコミットは未 push だった）。

書き直した見張りはこうである ――

- 合言葉は**手元の `.env.local` から読む。** テストに値を書かない
- 見るのは `git ls-files -co --exclude-standard`（＝**公開されるもの**）全部。
  4ファイルだけ見ていたのが、そもそも狭かった
- 一致したら**ファイル名だけ**を出す。値は出さない
- `.env.local` が無い環境では、**黙って通さず「突き合わせを省いた」と言う。**
  相手が居ないのに緑になるテストは、無いより悪い
- 「未設定ならこれ」の既定値をコードに持たせない、も別に見張る

確かめたら消す（確かめずに置いた見張りは、0件と嘘をつく）。
