### C-8. 辞退理由を必須にした（0008）

原典は `withdraw_reason_id` を NULL 可のままにしていたが、コメントは
「自由入力にすると集計が死ぬため選択式」「辞退理由の分布はチャネルの質を
表す」と述べている。分布を指標として読むなら、母数から静かに抜ける行が
あってはならない。

NULL を許すと「まだ聞けていない」「聞いたが答えなかった」「記録し忘れた」が
すべて同じ NULL になり、分布の合計が辞退件数に届かない理由を誰も
説明できなくなる。理由不明は「理由が無い」ではなく「未確認という事実がある」と
捉える（原則7）。受け皿として `withdraw_reasons` に `unconfirmed`（未確認）を
置き、本番の参照データにも入れた。

「未確認」が分布のどれだけを占めるかは、そのまま運用の質を表す。
NULL で隠れているより、見えるところに出ているほうがよい。
