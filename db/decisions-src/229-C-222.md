## C-222 多層序列を廃止し、権限を Hitler.md の1段へ集約した

依頼者の指示 ――「その序列を変えろ」「Hitler より下のものは全て変えていい。
全体を最適構成にするんだ」。

#### 何が問題だったか

序列が8層あった。

```
.audit/ > .consultant/ > SUPERVISOR.md > vision.md > director.md > domain.md > CLAUDE.md > process.md
```

`Hitler.md` を最上位に足した時点で9層になり、**各文書が「自分は何層目か」を
宣言する記述を持っていた。** 層を1つ動かすたびに8箇所を直す形で、
実際このセッション中に3回書き換えている。

★ **序列そのものが、複製してはならない要件の複製だった。**

#### 決めたこと

★★ **権限は `Hitler.md` だけが持つ。他のすべての文書に上下を付けない。** ★★

- **`Hitler.md` に無い条件は、作業を止める根拠にならない。**
  各文書は手順と事実を書く場所であり、そこに書いてあることを理由に実装を差し止めない。
- 食い違ったら `Hitler.md` に照らす。`Hitler.md` が何も言っていない事柄なら
  **それは規律の問題ではない。** 妥当なほうを採り、理由をここに残す。
- `Hitler.md` は監査所見も退けられる（依頼者指示）。ただし
  **退けた事実は消さない。**「所見が無かったことにする」は `Hitler.md` §4 の虚偽報告。

これで S1〜S13 は規律から**診断**へ格下げされた。落ちても事実として報告するだけで、
実装は止まらない。ただし **S7（検査の側を緩めない）は残す** ――
`Hitler.md` §4 の虚偽報告の禁止と同じ内容だからである。

#### 畳んだ2文書

| | なぜ空になったか |
|---|---|
| `SUPERVISOR.md` | 存在理由が**権限境界**だった。序列を廃止した時点で、権限の条文（監督官の承認・チャット限定の変更権）が全部無効になった |
| `vision.md` | 序列上の枠を確保するためだけに置かれていた。**理念は最後まで受け取っていない**（実行⑥から2週間）。序列が無ければ枠も要らない |

★ **空の文書を序列のために置かない。**

中身は捨てずに移した。

- `director.md` へ ―― UX判断4項目、`vision.md` に暫定で効いていた PRODUCT VISION の引用
- `process.md` へ ―― 「観察 → 診断 → 設計 → 確認」。
  ★ 旧 `SUPERVISOR.md` はこれを**監督官の承認という関門**にしていた。
    承認者が居なくなったので、**手順として残し、関門ではなくした。**

ルート直下の規律文書は 10本 → 8本（S2 と `.consultant/STRUCTURE.md` §2 を同じ差分で直した）。

#### 併せて解消した矛盾

`director.md`「一覧の数字には**単位と母集団を添える**」と
`CLAUDE.md`「単位と母集団は**画面に書かない**（C-62）」が正面から矛盾していた。

**C-62 を残した。** 実行⑩の依頼者指摘で `unit-note` / `footnote` / `Card` の `note` /
`readonly-note` をまとめて外した経緯があり、一般原則より**記録された明示指示が強い。**
`director.md` の側を直し、根拠と単位は画面ではなくクエリのコメントと本書に置くと明記した。

#### 封印との衝突（実測）

`.audit/MANIFEST.sha256` は `.audit/*` だけでなく **ルート規律文書6本**
（`AGENTS.md` `CLAUDE.md` `SUPERVISOR.md` `director.md` `domain.md` `process.md`）と
`.cursor/rules/supervisor-layer.mdc` `.githooks/*` `audit.yml` を封印している。

★ とくに `.cursor/rules/supervisor-layer.mdc` は `alwaysApply: true` で Cursor が毎回読む。
**廃止した8層序列と「監督官の承認が無ければ UI 実装を開始しない」が、
機械可読の形で生き残っていた。** 封印されているため実装セッションからは直せず、
依頼者が `kurosaki install` で再封印してから書き換えた。
**憲法が2つある状態**だったので、ここを直さないと以後の整理が全部その上に積まれた。

**この差分の後、再度 `kurosaki install` が要る。** 封印は改修前の状態で焼かれている。
