### C-60. 「やること」のリンクが 404 だった ―― 画面から点を入れる唯一の経路が壊れていた

C-59 を確かめている途中で踏んだ。

「柏木 朔 さんの二次面接を評価する」を押すと **404** になる。

```
v_open_tasks.source_id  = 評価のID（0014:68 e.id AS source_id）
画面のリンク             = /applications/{source_id}
```

`source_id` は**評価の ID** であって応募の ID ではない。ビューには
`application_id` が別にあるのに、`listDerivedTasks` がそれを選んでいなかった。

これが効いていた範囲は狭くない。**採点の入口は応募の画面にしかなく、
そこへ行く導線はこのリンクだけだった。** つまり実行⑨の終わりの時点で、
**画面から点を入れる手段が1つも無かった。**

テストは通っていた。リンク先が開けることを誰も確かめていなかったからである。
`tests/33` に、やることが名指しする応募が実際に引けることを固定した。

**出しているものが押せるかは、押して確かめないと分からない。**
