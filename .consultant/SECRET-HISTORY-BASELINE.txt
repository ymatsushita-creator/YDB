# 履歴に在る秘密の台帳 —— git 履歴で追加された .env 系のパス
#
# ★ 生成物ではない。**人間の承認を伴う台帳である。** 追加は依頼者の明示指示のみ。
# ★ S9（`pnpm structure`）がこの一覧と現状を突き合わせる ――
#   ここに無いパスが履歴に現れたら落ちる。**新しい漏洩は素通りできない。**
# ★ ラチェットである。減ったときも落ちる ―― 履歴から除去したら台帳を締め直すこと。
#   締め忘れた台帳は「1件のままだ」と嘘をつき、次に増えた1件を隠す。
#
# ─────────────────────────────────────────────────────────────
# なぜ据え置くのか
#
# S9 を緑にする手段は履歴の除去（`git filter-repo`）だけである。
# しかし `Hitler.md` §4 は「履歴改変」を**人間の明示指示があっても実行しない**禁止事項と
# している。**つまり S9 は永久に赤い。**
#
# ★★ 永久に赤い検査は、新しい漏洩を検知できない。 ★★
#   赤が既定になった時点で、次に別の `.env` が履歴へ入っても出力は変わらない。
#   既知の1件を台帳へ据え置き、**増分だけを落とす**形にした（S13 と同じ作り）。
#
# これは検査を緩めたのではない。**既知の1件は下に列挙されたまま消えない。**
# 緩めるなら条件を消せばよく、そうしていない（`Hitler.md` §4「結果の虚偽報告」の禁止）。
# ─────────────────────────────────────────────────────────────
#
