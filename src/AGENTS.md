# src/ —— 実装

```
pnpm verify:fast
```

- `commands/` 書き込み判定 ／ `queries/` 読み取り ／ `auth/` 層と引換券 ／ `import/` 受領データの読み取り ／ `ai/` モデル呼び出し ／ `db/` 接続とマイグレーション。**この境界を越えない。**
- 必須値・参照先・形式・サイズは**コマンド側で再検証する**（画面の検証を根拠にしない）。
- 導出値（確度・順位・集計）を直接 UPDATE しない。
- 日付は `jst_date()` / `jst_today()`。
- 追記専用テーブルの訂正は**打ち消し行**で行う。
- 実データはリポジトリの外。受け入れ口は `scripts/intake-dir.ts` だけで、中を指す指定は拒否される。
- モデルは Anthropic の最新世代を使う（`ai/client.ts`）。鍵は環境変数。**コードにもテストにも書かない。**
